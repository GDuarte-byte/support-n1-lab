# Support N1 Decision Lab

Ferramenta interativa de estudo para triagem de incidentes de suporte técnico, conectividade e segurança.

## O que ela faz

- Organiza o primeiro atendimento por escopo, impacto e urgência.
- Sugere uma sequência segura de investigação para três cenários: rede/DNS, computador/aplicativo e segurança.
- Mostra comandos ou evidências úteis para registrar no atendimento.
- Gera um resumo copiável para ticket, inteiramente no navegador.

## Limites importantes

Este é um projeto educacional de portfólio. Ele não executa comandos, não coleta dados e não substitui políticas internas, monitoramento ou resposta profissional a incidentes. Não informe senhas, tokens ou dados sensíveis na ferramenta.

## Tecnologias

HTML, CSS e JavaScript puro — sem dependências e sem back-end.

## Como executar

Abra `index.html` em um navegador ou publique os arquivos como um site estático.

## Contexto de portfólio

Criado por Gabriel Duarte Tourinho para demonstrar raciocínio de suporte N1, documentação técnica, fundamentos de redes e escalonamento responsável em segurança.
